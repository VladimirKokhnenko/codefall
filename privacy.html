Privacy Policy

Codefall screen saver · effective 20 September 2026

Summary

Codefall does not collect, store, transmit or share any personal data. The application has no network functionality at all.

Data the application does not collect

  • No personal information, account, sign-in or registration.
  • No analytics, telemetry, usage statistics or crash reports.
  • No advertising identifiers and no third-party SDKs.
  • No access to your location, contacts, microphone or camera.

Data stored on your device

Codefall keeps its settings in a local profile file and a small diagnostic log in your Windows user profile, in the folder %LOCALAPPDATA%\Codefall. These files never leave your computer. They are not removed automatically when the application is uninstalled; you may delete the folder at any time.

The "Photo frame" mode reads image files from a folder you choose. The images are displayed on screen only; they are not copied, indexed, uploaded or analysed.

Windows integration

When you open Codefall from the Start menu, it copies its files into %LOCALAPPDATA%\Codefall\app and registers itself as your current screen saver in the Windows settings for your user account (HKEY_CURRENT_USER\Control Panel\Desktop). This is how Windows locates and starts a screen saver. No other system settings are changed. Removing the application from Windows and starting the screen saver once removes this registration and the copied files.

Microsoft Store

If you install Codefall from the Microsoft Store, Microsoft may collect installation and update information under the Microsoft Privacy Statement. Codefall itself receives none of this data.

Children

Codefall is suitable for all ages and collects no data from anyone, including children.

Changes

If this policy ever changes, the new version will be published at this address with a new effective date.

Contact
