Политика конфиденциальности

Заставка Codefall · действует с 20 сентября 2026 г.

Коротко

Codefall не собирает, не хранит, не передаёт и не раскрывает никакие персональные данные. У приложения нет сетевых функций.

Чего приложение не собирает

  • Никаких персональных данных, учётных записей, входа или регистрации.
  • Никакой аналитики, телеметрии, статистики использования и отчётов о сбоях.
  • Никаких рекламных идентификаторов и сторонних SDK.
  • Нет доступа к местоположению, контактам, микрофону или камере.

Данные на вашем устройстве

Настройки Codefall хранятся в локальном файле профиля, рядом — небольшой диагностический журнал, в папке вашего профиля Windows %LOCALAPPDATA%\Codefall. Эти файлы не покидают ваш компьютер. При удалении приложения они не удаляются автоматически; папку можно удалить в любой момент.

Режим «Фоторамка» читает изображения из выбранной вами папки. Они только показываются на экране — не копируются, не индексируются, не отправляются и не анализируются.

Интеграция с Windows

При запуске Codefall из меню «Пуск» приложение копирует свои файлы в %LOCALAPPDATA%\Codefall\app и регистрирует себя как текущую заставку в настройках Windows вашей учётной записи (HKEY_CURRENT_USER\Control Panel\Desktop) — именно так Windows находит и запускает заставку. Другие системные настройки не меняются. Удаление приложения из Windows и один запуск заставки после этого снимают регистрацию и удаляют скопированные файлы.

Microsoft Store

При установке из Microsoft Store корпорация Microsoft может собирать сведения об установке и обновлениях в соответствии с Заявлением о конфиденциальности Microsoft. Сам Codefall этих данных не получает.

Дети

Codefall подходит для любого возраста и не собирает данные ни у кого, включая детей.

Изменения

Если политика изменится, новая версия будет опубликована по этому адресу с новой датой вступления в силу.
